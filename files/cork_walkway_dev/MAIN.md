# MAIN — 코르크 산책로 시공 예상도 프로그램 (Windows 실행파일)

> 이 파일은 프로젝트의 **총괄 지시서**다. Claude Code는 이 파일을 먼저 읽고, 아래 "실행 순서"에 따라 `modules/` 폴더의 MD 파일을 **하나씩 읽고 구현 → 테스트 → 보고**한 뒤 다음 모듈로 넘어간다.
> 프로젝트 루트의 `CLAUDE.md`에는 "작업 시작 시 MAIN.md를 읽고 따를 것"만 적는다.

---

## 1. 목적과 사용 장면
- 영업 담당자가 **고객 현장에서 흙길 사진을 찍고**, 몇 분 안에 **코르크 포장 시공 후 가상 사진**을 만들어 고객에게 보여준다.
- 입력: 현장 사진 1장(Windows 노트북·태블릿 카메라 촬영, 또는 휴대폰 사진을 PC로 옮긴 파일)
- 출력: 흙길만 코르크 포장으로 바뀐 예상도, 전·후 비교 화면, 비교 이미지·PDF 파일
- 자재는 **코르크 포장으로 고정**한다. 자재 사진 업로드·자재 분석 단계는 만들지 않는다. 대신 코르크 색상 프리셋을 고른다.

## 2. 확정된 설계 결정
| 항목 | 결정 | 이유 |
|---|---|---|
| 대상 OS | Windows 10/11 64비트 | 사용자 요구 |
| 형태 | 데스크톱 실행파일. **웹앱 아님** | 사용자 요구 |
| 언어 | Python 3.11 | 이미지 처리·AI 모델 라이브러리가 가장 풍부 |
| GUI | PySide6 (터치 대응 큰 버튼 UI) | 네이티브 창, 태블릿 터치 지원 |
| 이미지 처리 | OpenCV, NumPy, Pillow, pillow-heif | 표준 라이브러리 |
| 길 영역 지정 | onnxruntime + 경량 SAM 계열 ONNX 모델(터치 1~2회) | 오프라인, CPU 동작 |
| 기본 렌더링 | **로컬 렌더링(OpenCV)** — 인터넷 불필요, 사진 외부 전송 없음 | 현장 통신 불안정, 고객 사진 보호, 즉시 결과 |
| 고품질 모드 | **Gemini API (선택, 기본 꺼짐)** — 로컬 결과를 사진처럼 다듬음 | 사실감 향상이 필요할 때만 |
| 실행 중 Claude API | **사용하지 않음** | 자재가 고정이라 분석이 불필요. 전송 지점을 줄임 |
| 개발 도구 | Claude Code + 프로젝트 스킬(`.claude/skills/cork-render/`) | 유지보수용 |
| 배포 | ① 포터블 zip(압축 풀고 바로 실행) ② Inno Setup 설치본(관리자 권한 불필요) | 사용자 요구 |
| 빌드 | **빌드 스크립트만 작성, 실행 금지** | 사용자가 검토 후 직접 빌드 |

## 3. 전역 규칙 (모든 모듈 공통)
1. **길 마스크 바깥 픽셀은 원본과 100% 동일**해야 한다. 최종 합성은 원본 해상도에서 한다.
2. 원본 사진 파일을 덮어쓰지 않는다.
3. 결과물에는 "가상 시공 예상도 — 실제 시공 결과와 다를 수 있음" 표기를 기본으로 넣는다(설정에서 끌 수 있음).
4. 원본에 없는 사물(사람, 나무, 시설물)을 만들지 않는다.
5. 한글 경로 지원: 이미지 읽기·쓰기는 `np.fromfile + cv2.imdecode`, `cv2.imencode + tofile`을 쓴다.
6. API 키는 코드·설정 파일에 넣지 않는다(Windows 자격 증명 관리자 저장, 화면 표시는 마스킹).
7. 존재가 불확실한 라이브러리·함수·모델은 쓰지 않는다. 확인이 필요하면 주석에 `# 확인 필요:`로 표시하고 대안을 적는다.
8. 무거운 작업은 UI를 멈추지 않도록 작업 스레드에서 실행한다.

## 5. 모듈 진행 규칙
각 모듈마다 아래를 반드시 지킨다.
1. 해당 MD를 끝까지 읽는다.
2. "인터페이스"에 적힌 함수·클래스 이름과 입출력을 그대로 지킨다.
3. 구현 후 해당 모듈의 테스트를 작성하고 `pytest`로 실행한다.
4. 아래 형식으로 보고한 뒤 다음 모듈로 넘어간다.
```
[모듈 n 완료 보고]
- 생성/수정 파일:
- 테스트 결과: 통과 x / 실패 y
- 완료 기준 충족 여부: (항목별 O/X)
- 미해결·확인 필요 사항:
```
5. 테스트 실패나 완료 기준 미충족이 있으면 다음 모듈로 넘어가지 말고 원인과 해결안을 보고한다.
