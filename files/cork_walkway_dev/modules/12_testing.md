# 12. 테스트·점검 (v2)

## 단위 테스트 (`tests/`)
| 대상 | 핵심 확인 |
|---|---|
| image_io | 한글 경로, EXIF 회전, HEIC, 메타데이터 제거 |
| segmentation | 모델 없음 동작, 점 1개 IoU, 페더 경계 |
| perspective | 4점 추정 오차, 꼬인 4점 거부 |
| cork_material | 프리셋 로드, 타일 이음매, seed 재현성 |
| render_local | 그림자 유지, 캐시 속도 |
| compositor | 무변경 검증 100회, 위반 검출 |
| gemini_hq | 모의 응답으로 정렬·합성·실패 전환, 금지 API 정적 검사 |
| gemini_convert (v2) | 가짜 서버(`httpx.MockTransport`)로 성공·밀림·해상도 차이, 전체 변경·다른 사진·변화 없음·할당량·무료 등급 실패, 참고 사진 유무, 확인 전·설정 꺼짐 요청 0건, 작은 구멍만 메움 |
| quick_window (v2) | 사진만 올리면 자동 변환→비교→저장, 실패 후 [다시 만들기], 설정 꺼짐·확인 취소 시 요청 0건, 전송 내역 일치 |
| privacy | 전송 이미지 EXIF 없음·크기 제한, 로그 base64·키(`AIza…`,`AQ.…`) 없음, temp 정리, 허용 호스트·금지 모듈 정적 검사 |
| export | 한글 파일명, PDF 1페이지 |

- 테스트 이미지는 코드로 생성(초록 배경 + 갈색 사다리꼴 길 + 그림자 띠 + 길 위 회색 원형 물체)
- **테스트에서 실제 Gemini API를 호출하지 않는다**(요금·외부 전송). 실제 호출 확인은 현장 점검에서 사용자 승인 후 합성 이미지 또는 동의받은 사진으로만 한다
