# 08. 화면 (v2: 간편 화면 기본, 단계별 화면 보조)

## 목적
현장에서 고객 앞에서 **사진만 올리면 끝나는** 화면. 노트북 마우스와 태블릿 터치 모두 지원.

## 간편 화면 (기본, `app/ui/quick_window.py`, `python -m app.main`)
### 흐름
```
[사진 열기] / 카메라 / 창에 끌어놓기
  → 비교 화면에 '시공 전' 표시
  → (설정 꺼짐·키 없음이면) 사유 + "[설정]에서 확인" 안내, 전송 0건
  → (이번 실행 첫 전송이면) 전송 확인 창: 보낼 이미지 미리보기·해상도·대상·설명 → [보내기]/[취소]
  → Gemini 자동 변환(작업 스레드, 진행 표시 + [취소])
  → 결과(검증 통과분만) → 전·후 비교 + 하단 [저장]
```
- 사진을 열면 **바로 변환을 시작**한다(추가 클릭 없음).
- 다른 사진을 열면 진행 중 변환 결과는 버린다(세션이 바뀐 결과를 화면에 쓰지 않음).

### 화면 구성
- 상단: [사진 열기](강조) [카메라로 촬영](카메라 있을 때) · 색상(프리셋 콤보) · [다시 만들기] · 오른쪽 [전송 내역] [설정]
- 가운데: 사진 전 = 안내 문구, 사진 후 = 전·후 비교(`CompareView`)
- 알림 줄(배너), 진행 줄(문구 + 진행 막대 + [취소])
- 하단(결과가 있을 때만): 비교 방식 [가운데 선] [나란히] [전·후 전환] · 현장 이름 · [저장]
- 색상을 바꾸면 자동으로 다시 보내지 않는다(호출마다 요금). "[다시 만들기]를 누르면 이 색상으로 다시 만듭니다" 안내

### 규칙
- 전송 확인·전송 내역은 **실제로 보내는 객체(GeminiConvert)의 것**을 쓴다(창이 따로 만들면 내역이 어긋남)
- 저장은 검증된 결과(`session.verified`)가 있을 때만 활성
- 설정 화면 문구: "Gemini 사용 (현장 사진 축소본이 인터넷으로 전송됨)", "결제(Billing)가 연결된 유료 프로젝트의 키임을 확인함 — 무료 등급 키는 이미지 변환 불가"
- 설정 누락·형식 오류로 창을 만들 수 없으면 시작 시 오류 창을 띄우고 종료한다(`app/main.py`)

## 단계별 화면 (보조, `app/ui/main_window.py`, `python -m app.main --classic`)
v1 화면을 유지한다. 인터넷이 없을 때 로컬 렌더로 예상도를 만든다.
- ① 사진 → ② 길 지정(SAM 터치·브러시·다각형) → ③ 확인(원근 4점, 길 폭, 프리셋) → ④ 결과(전·후 비교, [고품질로 다듬기], [저장], [프레젠테이션])
- 프레젠테이션 모드: 전체 화면, 비교 슬라이더, 색 칩 즉시 전환(캐시 2초 이내), ESC 종료

## 기술 요구
- 무거운 작업은 작업 스레드(`app/ui/workers.py`의 `Runner`, 이유는 파일 주석 참조), 진행 표시와 취소
- 고DPI 대응, 한글 폰트(맑은 고딕) 기본, 버튼 최소 높이 40~48px
- 오류 메시지는 "무엇이 안 됐는지 + 어떻게 하면 되는지" 형식

## 인터페이스
```python
# app/ui/quick_window.py
class QuickWindow(QMainWindow):
    def __init__(self, config: dict, runner: Runner | None = None, converter: GeminiConvert | None = None)
    def open_photo(self, path: str) -> None
    def set_session(self, img: np.ndarray, name: str) -> None      # 새 사진 + 자동 변환 시작
    def start_convert(self) -> None                                 # [다시 만들기]
    def save(self) -> None
```

## 완료 기준

- [ ] 실패 시 사유 표시, [다시 만들기]로 재시도 성공
- [ ] 설정 꺼짐·전송 확인 [취소] 시 요청 0건
- [ ] 저장 시 시공 후·전후 비교 파일 생성
- [ ] 1366×768 화면과 태블릿 세로 모드에서 버튼이 잘리지 않음, 작업 중 창 이동·크기 변경 시 멈추지 않음
