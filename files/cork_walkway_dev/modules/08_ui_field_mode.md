# 08. 화면 (현장 모드·프레젠테이션 모드)

## 목적
현장에서 고객 앞에서 **빠르고 헷갈림 없이** 쓸 수 있는 화면. 노트북 마우스와 태블릿 터치 모두 지원.

## 현장 모드 (기본 화면)
- 상단 단계 표시: ① 사진 → ② 길 지정 → ③ 확인 → ④ 결과
- 큰 버튼(최소 48px 높이), 단계마다 버튼 1~2개만 강조
- ① 사진: [카메라로 촬영] [사진 열기] [최근 사진]
- ② 길 지정: 길을 터치하라는 안내, [제외 점 모드] [브러시] [지우개] [되돌리기]
- ③ 확인: 원근 격자 표시, 4점 조정(필요 시), 길 폭 입력(선택), 코르크 프리셋 선택
- ④ 결과: 전·후 비교, [색상 바꾸기] [고품질로 다듬기(Gemini, 켜진 경우)] [저장] [프레젠테이션]
- 고급 설정(명암 유지, 색 맞춤, 페더, 마감선)은 접힌 패널에 둔다

## 프레젠테이션 모드 (고객용)
- 전체 화면, 상단·하단 도구 숨김
- **전·후 비교 슬라이더**(가운데 세로선을 끌어 비교), 좌우 나란히 보기, 전/후 전환 버튼
- 코르크 색상 프리셋을 하단 색 칩으로 즉시 전환(캐시로 2초 이내)
- "가상 시공 예상도" 표기 상시 노출
- ESC 또는 화면 모서리 버튼으로 종료

## 기술 요구
- 무거운 작업은 `QThreadPool`/`QRunnable`, 진행 표시와 취소 버튼
- 고DPI 대응, 한글 폰트(맑은 고딕) 기본
- 오류 메시지는 "무엇이 안 됐는지 + 어떻게 하면 되는지" 형식
- 키보드 단축키: Ctrl+O 열기, Ctrl+Z 되돌리기, F5 프레젠테이션, Ctrl+S 저장

## 완료 기준
- [ ] 사진 열기부터 결과 저장까지 클릭 7회 이내(자동 마스크가 맞는 경우)
- [ ] 1366×768 노트북 화면과 태블릿 세로 모드에서 버튼이 잘리지 않음
- [ ] 작업 중 창 이동·크기 변경 시 멈추지 않음
