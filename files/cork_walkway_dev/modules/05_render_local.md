# 05. 로컬 렌더링

## 목적
코르크 텍스처를 길 위에 원근에 맞게 입히고, 원래 사진의 빛과 그림자를 살려 자연스럽게 만든다.

## 절차
1. **원근 투영**: 평면 텍스처를 `cv2.warpPerspective`로 원본 해상도에 투영(INTER_LINEAR, 경계는 마스크로 자름)
2. **명암·그림자 유지**
   - 원본을 LAB로 변환, 길 영역 L 채널에서 저주파 명암 추출
   - 흙 자체의 얼룩(바퀴 자국, 돌) 대신 **빛과 그림자만** 남기도록 가이드 필터 또는 큰 시그마 블러 사용(시그마는 이미지 크기 비례)
   - 명암 비율 = 추출값 / 길 영역 평균 → 텍스처 L에 곱함(`shading_strength`로 혼합)
3. **색 맞춤**: 장면 화이트밸런스에 맞게 텍스처 a·b 채널을 길 주변 영역 평균 쪽으로 약하게 이동(`color_match`)
4. **원근 흐림**: 먼 쪽은 원본 사진의 선명도에 맞춰 약하게 블러(사진 초점 차이 재현)
5. **가장자리 마감선(선택)**: 길 경계 안쪽으로 `edge_band_px` 폭의 마감 띠(프리셋 색보다 약간 어둡게)
6. **접촉 음영(선택)**: 경계 안쪽 몇 px를 약하게 어둡게

## 속도
- 프리셋 변경 시 원근 투영 좌표맵(`cv2.remap`용)을 캐시해 재사용
- 미리보기는 축소본으로 먼저 보여주고, 저장 시 원본 해상도로 다시 렌더링
