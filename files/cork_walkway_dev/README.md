# 코르크 산책로 시공 예상도 (CorkWalkway)

> **고객 현장 사진을 외부 AI로 보내기 전에 회사 정보보호 규정과 고객 동의 여부를 확인하십시오.**
> (기본 설정은 완전 오프라인입니다. 외부 전송은 사용자가 켠 "고품질 모드"에서만 일어납니다.)

현장에서 흙길 사진을 찍고, 몇 분 안에 **흙길만 코르크 포장으로 바꾼 가상 시공 사진**을 만들어 고객에게 보여주는 Windows 프로그램입니다.
결과물에는 "가상 시공 예상도 — 실제 시공 결과와 다를 수 있습니다" 표기가 기본으로 들어갑니다.

## 1. 설치

| 방법 | 설명 |
|---|---|
| 포터블 | `CorkWalkway-<버전>-portable.zip` 압축을 풀고 `CorkWalkway\CorkWalkway.exe` 실행 |
| 설치본 | `CorkWalkway-<버전>-setup.exe` 실행. 관리자 권한 불필요, `%LOCALAPPDATA%\Programs\CorkWalkway`에 설치, 시작 메뉴·바탕화면 바로가기, [앱 및 기능]에서 제거 |

- 대상: Windows 10/11 64비트. 노트북·태블릿(터치) 모두 지원
- 서명되지 않은 exe는 처음 실행할 때 **Windows SmartScreen 경고**가 뜰 수 있습니다([추가 정보] → [실행]). 배포 전에 코드 서명 인증서 적용을 권장합니다(아래 7장).

## 2. 사용 방법 (현장 모드)

| 단계 | 할 일 |
|---|---|
| ① 사진 | [카메라로 촬영](카메라가 있을 때만 보임) / [사진 열기] / [최근 사진]. 사진 파일을 창에 끌어다 놓아도 됩니다. JPG·PNG·HEIC 지원 |
| ② 길 지정 | 흙길을 **한 번 터치**. 덜 잡히면 길을 한 번 더 터치. 길 위 사람·물체는 [제외 점 모드](또는 마우스 오른쪽 클릭·길게 누름)로 터치. [브러시]·[지우개]·[다각형](꼭짓점을 찍고 두 번 누르거나 [다각형 완료])으로 다듬기, [되돌리기]·[다시 실행] |
| ③ 확인 | 파란 원근 격자가 길과 맞는지 확인. 어긋나면 [4점 조정]으로 모서리를 끌기. 굽은 길은 "굽은 길(3~5구간)" 선택. 실제 길 폭을 알면 입력(모르면 2.0m 가정). 코르크 색상 선택. 고급 설정(명암 유지·색 맞춤·입자 크기·경계 페더·마감선·접촉 음영)은 접혀 있음 |
| ④ 결과 | 가운데 선을 끌어 전·후 비교. [색상 바꾸기], [고품질로 다듬기](켜진 경우), 현장명 입력 후 [저장], [프레젠테이션] |

- **프레젠테이션 모드**(F5): 전체 화면, 슬라이더/나란히/전·후 전환, 하단 색 칩으로 즉시 색 변경. ESC 또는 오른쪽 위 ✕로 종료
- 단축키: Ctrl+O 열기, Ctrl+Z 되돌리기, Ctrl+Y 다시 실행, F5 프레젠테이션, Ctrl+S 저장
- **저장되는 파일**(사용자가 고른 폴더, 같은 이름이 있으면 `_2`를 붙여 절대 덮어쓰지 않음):
  `현장명_YYYYMMDD_HHMM_시공후.jpg`(원본 해상도), `_전후비교.jpg`, `_예상도.pdf`(A4 가로 1페이지), `_작업설정.json` + `_마스크.png`(같은 결과 재현용). 사진 정보(EXIF·GPS)는 저장하지 않습니다.
- 길 밖이 원본과 **완전히 같은** 파일이 필요하면 `config.yaml`에서 `export.image_format: png`로 바꾸고 설정에서 표기를 끄세요(JPG는 압축 특성상 미세한 차이가 생깁니다).

## 3. 고품질 모드 (Google Gemini, 선택 기능, 기본 꺼짐)

로컬 결과를 Gemini 이미지 모델로 더 사진처럼 다듬습니다. 실패하면(인터넷 없음, 한도 초과, 안전 필터, 정렬 실패 등) 로컬 결과를 그대로 쓰고 사유를 한 줄로 표시합니다.

1. [설정]에서 "고품질 모드 사용" 체크, API 키 입력(Windows 자격 증명 관리자에 저장, 화면에는 앞 4자리만 표시)
2. **"Cloud Billing이 연결된 유료 키임을 확인함"** 체크(체크 전에는 동작하지 않음)
3. Google AI Studio의 **Logs and Datasets → Settings에서 Generate Content API 로깅을 끄기**(권장). 앱은 요청마다 `store=false`를 보내지만, 2026-10-26 이후 새 유료 프로젝트는 기본이 "요청 저장"이므로 이중으로 막아 두세요.
4. 보내기 전 확인 창에서 보낼 이미지·해상도·대상을 확인하고 [보내기]. "이번 실행 동안 묻지 않기"만 가능(다음 실행에서 다시 물음)

> 유료 등급에서도 Google은 정책 위반 감지를 위해 요청·응답을 일정 기간 기록할 수 있습니다. 완전한 무보관이 필요하면 Vertex AI 무보관(ZDR) 구성을 사용해야 합니다.

- 모델: `config.yaml`의 `gemini.model` (기본 `gemini-nano-banana-2.1`). **유료 키로 한 번 동작을 확인하세요.** 404·400 오류가 나면 `gemini-3.1-flash-image`로 바꿔 보세요.

## 4. 데이터 처리 안내

| 항목 | 처리 |
|---|---|
| 기본 동작 | 완전 오프라인. 실행 중 Claude API 등 다른 외부 호출 없음. 텔레메트리·자동 업데이트·원격 모델 다운로드 없음 |
| 외부 전송(고품질 모드만) | 대상 `generativelanguage.googleapis.com` 한 곳. 길 주변만 잘라낸 사진 일부 + 같은 영역 로컬 예상도 2장, 긴 변 1536px 이하, EXIF·GPS·파일명·현장명 없음, 인라인 전송(Files API·캐싱·대화 세션·검색 그라운딩 사용 안 함), `store=false` |
| 전송 내역 | 상단 [전송 내역]: 이번 실행의 전송 시각·대상·해상도·영역 크기(이미지 자체는 기록 안 함) |
| 임시 파일 | `%LOCALAPPDATA%\CorkWalkway\temp\` — 시작·종료 시 삭제 |
| 로그 | `%APPDATA%\CorkWalkway\logs\app.log` — 시각·단계·소요 시간·오류 종류만. 이미지·base64·API 응답·키는 기록하지 않음 |
| 설정 | `%APPDATA%\CorkWalkway\settings.json` — 선택값만(키 없음) |
| API 키 | Windows 자격 증명 관리자(서비스 이름 `CorkWalkway`). 프로그램을 제거해도 남으므로, 지우려면 먼저 설정에서 [키 삭제] |

## 5. 길 자동 지정 모델·코르크 자재

- **모델**: `models/` 폴더에 SAM 계열 ONNX 모델 2개를 넣으면 터치로 길을 자동 지정합니다. 없으면 브러시·지우개 수동 도구만으로 동작합니다. 출처·SHA-256·라이선스(Apache-2.0)는 [models/README.md](models/README.md) 참조. 앱은 모델을 인터넷에서 받지 않습니다.
- **코르크 프리셋**: `materials/cork/presets.yaml`. **색상(`base_colors`)과 입자 크기(`granule_mm`)는 예시값**이므로 실제 제품 자료로 바꾸세요.
- **제품 사진**: `materials/cork/<프리셋 id>/sample.jpg`를 넣으면 그 사진으로 질감을 만듭니다(가장 사실적). 표면을 정면에서 자와 함께 찍고, 사진 중앙 정사각 영역이 덮는 실제 폭을 `sample_width_m`(기본 0.3m)에 적으세요. 없으면 코드로 만든 질감(근사)을 씁니다.
- **글꼴**: `assets/fonts/`에 한글 글꼴(예: Noto Sans KR, OFL)을 두면 결과물 글자에 우선 사용, 없으면 Windows 맑은 고딕. **회사 로고**: `assets/logo.png`가 있으면 결과물 우측 하단에 작게 표시

## 6. 개발

```bat
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python -m app.main              rem 실행
.venv\Scripts\python -m pytest -q             rem 전체 테스트
.venv\Scripts\python -m pytest tests\test_compositor.py::test_random_100_all_pass   rem 테스트 하나
.venv\Scripts\python tests\bench.py           rem 12MP 단계별 성능 측정
```

- Python 3.11, 개발 지시서: `MAIN.md`, `modules/*.md`
- `exe` 옆에 `config.yaml`, `models\`, `materials\`를 두면 배포본 내장 파일보다 먼저 쓰입니다.

## 7. 빌드 (사용자가 검토 후 직접 실행)

1. Python 3.11 설치, (설치본이 필요하면) [Inno Setup 6](https://jrsoftware.org/isinfo.php) 설치
2. `models\`에 모델 파일 확인
3. `build_windows.bat` 실행 → Python 확인 → 빌드용 가상환경(`.venv-build`) → 의존성 설치 → **테스트(실패 시 중단)** → PyInstaller(`build.spec`, onedir) → `dist\CorkWalkway-<버전>-portable.zip` → (Inno Setup이 있으면) `dist\CorkWalkway-<버전>-setup.exe`
4. 버전 변경: `app/__init__.py`의 `__version__`과 `assets/version_info.txt`를 함께 바꿉니다.

### 빌드 후 확인 목록
- [ ] exe 더블클릭 실행, 콘솔 창 없음
- [ ] 파이썬이 없는 다른 PC에서 실행
- [ ] 카메라 촬영 동작(카메라 있는 기기)
- [ ] `models/` 인식(자동 마스크 동작: 길 한 번 터치로 주황색 영역이 잡힘)
- [ ] 한글 사용자명·한글 경로 PC에서 실행, 한글 폴더에 저장
- [ ] 고품질 모드(유료 키)로 1회 전송·결과 확인, [전송 내역] 확인
- [ ] 서명되지 않은 exe는 SmartScreen 경고가 뜰 수 있음 → 코드 서명 인증서(OV/EV)로 `signtool sign /fd SHA256 /tr <타임스탬프 URL> /td SHA256 dist\CorkWalkway\CorkWalkway.exe` 후 설치본도 서명

## 9. 성능 (개발 PC CPU, 합성 12MP 사진, `testsench.py`)

| 작업 | 측정 | 목표 |
|---|---|---|
| 사진 불러오기 + 마스크 준비(읽기 0.23 + 인코더 1.11초) | 1.37초 | 5초 이내 |
| 터치 1회당 마스크 갱신 | 0.26초 | 1초 이내 |
| 로컬 렌더링 12MP(텍스처 생성 포함 7.9 + 합성·검증 1.1초) | 9.05초 | 10초 이내 |
| 코르크 색상 프리셋 변경(캐시) | 0.82초 | 2초 이내 |
| 저장(4종) | 0.88초 | — |

- 화면에서는 사진을 연 뒤 나머지 프리셋 미리보기를 뒤에서 미리 만들어, 색 칩 전환이 캐시로 처리됩니다.
- 12MP 렌더는 목표와 여유가 작습니다(9.05/10초). 저장 시에는 미리보기에서 만든 텍스처를 재사용해 약 2초 짧아집니다. 느린 PC에서는 목표를 넘을 수 있습니다.

## 10. 알려진 한계
- 예상도는 근사입니다. 입자 크기 원근은 사진 한 장으로 길이를 추정한 **가정값**(휴대폰 기본 카메라 초점거리, 길 폭 미입력 시 2.0m)을 씁니다.
- 코드로 만든 코르크 질감은 근사입니다. 실제 제품 사진을 넣는 것을 권장합니다.
- 그림자 경계가 약간 부드러워지고, 사진 전체 노출(흐린 날)에는 코르크 밝기를 맞추지 않습니다.
- 자동 지정: 포함 점 1개 + 제외 점만 주면 길 일부가 빠질 수 있습니다(길을 한 번 더 터치). 그림자 위를 터치하면 그림자만 잡힐 수 있습니다.
- 고품질 모드: 길 주변에 무늬가 거의 없으면(민무늬 벽·하늘) 정렬에 실패해 로컬 결과를 유지합니다. 요청 중 [취소]해도 이미 보낸 요청은 서버에서 처리될 수 있습니다.
- PDF의 글자는 윤곽선으로 그려져 선택·복사할 수 없습니다.

## 11. 사용 도구
- 개발: Claude Code. 코딩 스킬 Ponytail(`DietrichGebert/ponytail`)은 **설치하지 않고 진행**(사용자 결정, 2026-11-04). 각 모듈의 ponytail-review는 수동 점검으로 대체
- 주요 라이브러리(`requirements.txt`, 버전 고정): PySide6 6.9.1, OpenCV 4.11, NumPy 2.2, Pillow 11.2, pillow-heif 0.22, onnxruntime 1.22, PyYAML, keyring 25.6, google-genai 2.34.0(선택 기능), pytest, PyInstaller 6.14.1
- 길 자동 지정 모델: MobileSAM(Apache-2.0) + Segment Anything 디코더(Apache-2.0) — [models/README.md](models/README.md)
