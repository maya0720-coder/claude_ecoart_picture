# 시공 시뮬레이터 (CorkWalkway)

> **고객 현장 사진을 외부 AI로 보내기 전에 회사 정보보호 규정과 고객 동의 여부를 확인하십시오.**
> (설치 직후에는 외부 전송이 꺼져 있습니다. [설정]에서 Gemini를 켜면, 사진을 열 때마다 **현장 사진 전체의 축소본**이 Google Gemini API로 전송됩니다. 사람 얼굴·차량 번호판 등이 함께 전송될 수 있습니다.)

현장에서 흙길 사진을 올리면 **사용자 조작 없이** Google Gemini가 **흙길만 코르크 포장으로 바꾼 가상 시공 사진**을 만들어 주고, 시공 전·후를 비교해 고객에게 보여주는 Windows 프로그램입니다.
결과물에는 "가상 시공 예상도 — 실제 시공 결과와 다를 수 있습니다" 표기가 기본으로 들어갑니다.

> 2026-11-05 프로그램 표시 이름을 "코르크 산책로 시공 예상도"에서 **시공 시뮬레이터**로 바꿨습니다. 실행 파일 이름(`CorkWalkway.exe`)과 사용자 데이터 폴더(`%APPDATA%\CorkWalkway`)는 기존 설정·키 호환을 위해 그대로입니다.

## 1. 설치

| 방법 | 설명 |
|---|---|
| 포터블 | `CorkWalkway-<버전>-portable.zip` 압축을 풀고 `CorkWalkway\CorkWalkway.exe` 실행 |
| 설치본 | `CorkWalkway-<버전>-setup.exe` 실행. 관리자 권한 불필요, `%LOCALAPPDATA%\Programs\CorkWalkway`에 설치, 시작 메뉴·바탕화면 바로가기, [앱 및 기능]에서 제거 |

- 대상: Windows 10/11 64비트. 노트북·태블릿(터치) 모두 지원
- 서명되지 않은 exe는 처음 실행할 때 **Windows SmartScreen 경고**가 뜰 수 있습니다([추가 정보] → [실행]). 배포 전에 코드 서명 인증서 적용을 권장합니다(아래 7장).

## 2. 사용 방법

### 간편 화면 (기본)
왼쪽 패널: ① 현장 사진 ② 바닥 소재 ③ 세부 요청(선택) → [시공 예상도 만들기]. 오른쪽: 사진·전후 비교·저장.
왼쪽 패널과 사진 사이의 세로 구분선을 끌어 패널 폭을 바꿀 수 있습니다(다음 실행에도 유지).
- **길 가장자리 마감재(경계석·자연석 등) 시공**(기본 켜짐): 길 양옆을 주변 환경에 어울리는 마감재(숲길은 자연석, 공원은 화강석 경계석 등)로 마감하도록 요청합니다. 마감재가 길 바깥 좁은 띠에 그려져도 길과 이어진 변경이라 결과에 포함됩니다.
- **길 위 나뭇가지·낙엽·돌 깨끗이 정리**(기본 켜짐): 길 위에 떨어진 잔가지·뿌리·낙엽·돌·쓰레기를 치우고 포장하도록 요청합니다. 끄면 길 위 물체를 그대로 둡니다.

0. (선택) **② 바닥 소재**를 고르고 **③ 추가 요청**을 적어 둡니다. 기본은 코르크(내추럴 브라운)입니다.
1. **[사진 열기]**(또는 사진 파일을 창에 끌어놓기, 카메라가 있으면 [카메라]). JPG·PNG·HEIC 지원
2. 이번 실행에서 처음 보낼 때만 **전송 확인 창**이 뜹니다. 보낼 이미지를 확인하고 [보내기]
3. 자동으로 Gemini가 변환합니다(보통 수십 초, 최대 1분). 진행 중 [취소] 가능
4. 결과가 나오면 **가운데 선을 끌어(또는 ← → 키) 시공 전·후 비교**. [가운데 선] [나란히] [전·후 전환]으로 보기 변경
5. 현장 이름을 입력하고 **[저장]**

- 소재·추가 요청을 바꾼 뒤 **[다시 만들기]**를 누르면 그 내용으로 다시 만듭니다(자동으로 다시 보내지 않음 — 호출마다 요금).
- **다른 소재 추가**: ② 바닥 소재의 [+ 소재 샘플 추가] → 바닥재 표면이 화면 가득 보이는 사진과 이름 입력. 사진은 긴 변 1024px로 줄이고 사진 정보(EXIF·GPS)를 지워 `%APPDATA%\CorkWalkway\materials\`에 저장합니다(최대 30개). 직접 추가한 소재만 [삭제]할 수 있습니다.
- **추가 요청**: 300자까지. 줄바꿈·제어문자는 정리되어 Gemini에 전달됩니다. 어떤 요청이든 길 밖은 바뀌지 않습니다(프로그램이 길 영역만 합성·검증).
- 길 안쪽이 덜 바뀌어 원본 흙이 얼룩처럼 남는 경우(코르크·흙 색이 비슷한 곳)는 자동으로 메웁니다.
- 실패하면 사유가 한 줄로 표시됩니다(아래 3장의 표). [다시 만들기]로 재시도하세요.
- 프로그램은 Gemini 결과를 그대로 쓰지 않고, 원본과 맞춘 뒤 **실제로 바뀐 길 영역만** 원본 해상도 사진에 합성합니다. 길 밖은 원본 그대로입니다.

### 단계별 화면 (오프라인 대안)
인터넷이 없을 때 `CorkWalkway.exe --classic`(개발 환경: `python -m app.main --classic`)으로 실행하면, 길을 직접 지정해 PC 안에서 예상도를 만드는 이전 화면이 열립니다.

| 단계 | 할 일 |
|---|---|
| ① 사진 | [카메라로 촬영](카메라가 있을 때만 보임) / [사진 열기] / [최근 사진]. 사진 파일을 창에 끌어다 놓아도 됩니다. JPG·PNG·HEIC 지원 |
| ② 길 지정 | 흙길을 **한 번 터치**. 덜 잡히면 길을 한 번 더 터치. 길 위 사람·물체는 [제외 점 모드](또는 마우스 오른쪽 클릭·길게 누름)로 터치. [브러시]·[지우개]·[다각형](꼭짓점을 찍고 두 번 누르거나 [다각형 완료])으로 다듬기, [되돌리기]·[다시 실행] |
| ③ 확인 | 파란 원근 격자가 길과 맞는지 확인. 어긋나면 [4점 조정]으로 모서리를 끌기. 굽은 길은 "굽은 길(3~5구간)" 선택. 실제 길 폭을 알면 입력(모르면 2.0m 가정). 코르크 색상 선택. 고급 설정(명암 유지·색 맞춤·입자 크기·경계 페더·마감선·접촉 음영)은 접혀 있음 |
| ④ 결과 | 가운데 선을 끌어 전·후 비교. [색상 바꾸기], [고품질로 다듬기](켜진 경우), 현장명 입력 후 [저장], [프레젠테이션] |

- **프레젠테이션 모드**(F5): 전체 화면, 슬라이더/나란히/전·후 전환, 하단 색 칩으로 즉시 색 변경. ESC 또는 오른쪽 위 ✕로 종료
- 단축키: Ctrl+O 열기, Ctrl+Z 되돌리기, Ctrl+Y 다시 실행, F5 프레젠테이션, Ctrl+S 저장
- **저장되는 파일**(사용자가 고른 폴더, 같은 이름이 있으면 `_2`를 붙여 절대 덮어쓰지 않음):
  `현장명_YYYYMMDD_HHMM_시공후.jpg`(원본 해상도), `_전후비교.jpg`, `_예상도.pdf`(A4 가로 1페이지), `_작업설정.json` + `_마스크.png`(같은 결과 재현용). 사진 정보(EXIF·GPS)는 저장하지 않습니다.
- 길 밖이 원본과 **완전히 같은** 파일이 필요하면 `config.yaml`에서 `export.image_format: png`로 바꾸고 설정에서 표기를 끄세요(JPG는 압축 특성상 미세한 차이가 생깁니다).

## 3. Gemini API 설정 (자동 변환에 필요)

1. [Google AI Studio](https://aistudio.google.com/apikey)에서 API 키를 만든 **프로젝트에 결제(Billing)를 연결**합니다. **무료 등급 프로젝트는 이미지 모델 할당량이 0이라 변환되지 않습니다.** Gemini 앱 구독(Google AI Pro 등)은 API 요금제와 별개입니다.
2. 프로그램 [설정]에서 **"Gemini 사용"** 체크, API 키를 붙여넣고 **[Save]**(Windows 자격 증명 관리자에 저장). 저장되면 "API 키를 저장했습니다: AQ.A…xxxx" 창이 뜹니다. '저장된 키' 칸의 **뒤 4자리**가 AI Studio에 보이는 키의 끝 4자리와 같은지 확인하세요
3. **"결제(Billing)가 연결된 유료 프로젝트의 키임을 확인함"** 체크(체크 전에는 동작하지 않음)
4. Google AI Studio의 **Logs and Datasets → Settings에서 Generate Content API 로깅을 끄기**(권장). 앱은 요청마다 `store=false`를 보냅니다.
5. 변환 1회마다 API 요금이 나갑니다(Google 가격표 참조).

> 유료 등급에서도 Google은 정책 위반 감지를 위해 요청·응답을 일정 기간 기록할 수 있습니다. 완전한 무보관이 필요하면 Vertex AI 무보관(ZDR) 구성을 사용해야 합니다.

> **API 키가 화면 캡처·메신저 등으로 노출되면 즉시 AI Studio에서 삭제하고 새로 발급**하세요.

| 화면 메시지(요지) | 조치 |
|---|---|
| 키의 프로젝트가 무료 등급 | 1번: 결제 연결 또는 결제된 프로젝트의 키로 교체 |
| 사용 한도 초과 / 오늘 한도 소진 | 잠시 후 / 내일 다시, AI Studio에서 한도 확인 |
| API 키가 거부됨 | 키 다시 입력, 결제 연결 확인 |
| 모델을 찾을 수 없음 | `config.yaml`의 `gemini.model` 확인(대안 `gemini-3.1-flash-image`) |
| 구도가 달라 맞출 수 없음 / 바뀐 영역을 찾지 못함 / 전체가 바뀜 | [다시 만들기] |
| 자동 변환을 할 수 없습니다 | [설정]에서 Gemini 사용·유료 키 확인·키 입력 |

- 모델: `config.yaml`의 `gemini.model` (기본 `gemini-nano-banana-2.1`)
- 자재 참고 사진: `materials/cork/<프리셋 id>/reference.jpg`가 있으면 함께 보내 색·질감을 맞춥니다(포장면만 찍힌 사진, 사람·전화번호·로고 없이).

## 4. 데이터 처리 안내

| 항목 | 처리 |
|---|---|
| 기본 동작 | 설치 직후 외부 전송 꺼짐. 실행 중 Claude API 등 다른 외부 호출 없음. 텔레메트리·자동 업데이트·원격 모델 다운로드 없음 |
| 외부 전송(간편 화면, Gemini 켠 경우) | 대상 `generativelanguage.googleapis.com` 한 곳. **현장 사진 전체의 축소본**(긴 변 1536px 이하) + 자재 참고 사진 또는 직접 추가한 소재 샘플 사진 + 추가 요청 글(적은 경우), EXIF·GPS·파일명·현장명·소재 이름 없음, 인라인 전송(Files API·캐싱·대화 세션·검색 그라운딩 사용 안 함), `store=false`. 이번 실행 첫 전송 전 확인 창 |
| 외부 전송(단계별 화면의 고품질 다듬기) | 길 주변만 잘라낸 사진 일부 + 같은 영역 로컬 예상도 2장(나머지 조건 동일) |
| 전송 내역 | 상단 [전송 내역]: 이번 실행의 전송 시각·대상·해상도·영역 크기(이미지 자체는 기록 안 함) |
| 임시 파일 | `%LOCALAPPDATA%\CorkWalkway\temp\` — 시작·종료 시 삭제 |
| 로그 | `%APPDATA%\CorkWalkway\logs\app.log` — 시각·단계·소요 시간·오류 종류·변경 영역 비율만. 이미지·base64·API 응답·키(`AIza…`·`AQ.…`)는 기록하지 않음 |
| 설정 | `%APPDATA%\CorkWalkway\settings.json` — 선택값만(키 없음) |
| 직접 추가한 소재 | `%APPDATA%\CorkWalkway\materials\custom_xxxxxxxx\` — 축소·메타데이터 제거한 샘플 사진 + 이름. [삭제]로 폴더째 지움. 추가 요청 글은 저장·로그하지 않음 |
| API 키 | Windows 자격 증명 관리자(서비스 이름 `CorkWalkway`). 프로그램을 제거해도 남으므로, 지우려면 먼저 설정에서 [키 삭제] |

## 5. 길 자동 지정 모델·코르크 자재

- **모델**: `models/` 폴더에 SAM 계열 ONNX 모델 2개를 넣으면 터치로 길을 자동 지정합니다. 없으면 브러시·지우개 수동 도구만으로 동작합니다. 출처·SHA-256·라이선스(Apache-2.0)는 [models/README.md](models/README.md) 참조. 앱은 모델을 인터넷에서 받지 않습니다.
- **코르크 프리셋**: `materials/cork/presets.yaml`. **색상(`base_colors`)과 입자 크기(`granule_mm`)는 예시값**이므로 실제 제품 자료로 바꾸세요.
- **제품 사진**: `materials/cork/<프리셋 id>/sample.jpg`를 넣으면 그 사진으로 질감을 만듭니다(가장 사실적). 표면을 정면에서 자와 함께 찍고, 사진 중앙 정사각 영역이 덮는 실제 폭을 `sample_width_m`(기본 0.3m)에 적으세요. 없으면 코드로 만든 질감(근사)을 씁니다.
- **글꼴**: `assets/fonts/`에 한글 글꼴(예: Noto Sans KR, OFL)을 두면 결과물 글자에 우선 사용, 없으면 Windows 맑은 고딕. **회사 로고**: `assets/logo.png`가 있으면 결과물 우측 하단에 작게 표시

## 6. 개발

```bat
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python -m app.main              rem 실행
.venv\Scripts\python -m pytest -q             rem 전체 테스트
.venv\Scripts\python -m pytest tests\test_compositor.py::test_random_100_all_pass   rem 테스트 하나
.venv\Scripts\python tests\bench.py           rem 12MP 단계별 성능 측정
```

- Python 3.11, 개발 지시서: `MAIN.md`, `modules/*.md`
- `exe` 옆에 `config.yaml`, `models\`, `materials\`를 두면 배포본 내장 파일보다 먼저 쓰입니다.

## 7. 빌드 (사용자가 검토 후 직접 실행)

1. Python 3.11 설치, (설치본이 필요하면) [Inno Setup 6](https://jrsoftware.org/isinfo.php) 설치
2. `models\`에 모델 파일 확인
3. `build_windows.bat` 실행 → Python 확인 → 빌드용 가상환경(`.venv-build`) → 의존성 설치 → **테스트(실패 시 중단)** → PyInstaller(`build.spec`, onedir) → `dist\CorkWalkway-<버전>-portable.zip` → (Inno Setup이 있으면) `dist\CorkWalkway-<버전>-setup.exe`
4. 버전 변경: `app/__init__.py`의 `__version__`과 `assets/version_info.txt`를 함께 바꿉니다.
5. **태블릿용 단일 실행 파일**: `build_windows.bat onefile` → `dist\CorkWalkway.exe` 하나만 복사해 실행합니다.
   - 대상: Windows 10/11 **x64** 태블릿(Surface Pro, 갤럭시북 등). Windows 11 ARM 태블릿은 x64 에뮬레이션으로 실행되며 느릴 수 있고, Windows 10 ARM·iPad·안드로이드 태블릿은 실행할 수 없습니다.

   - 화면이 작은 기기(1400×900 미만)에서는 최대화로 시작하고 최소 창 크기를 화면에 맞춥니다.

## 10. 알려진 한계
- 예상도는 근사입니다. 입자 크기 원근은 사진 한 장으로 길이를 추정한 **가정값**(휴대폰 기본 카메라 초점거리, 길 폭 미입력 시 2.0m)을 씁니다.
- 코드로 만든 코르크 질감은 근사입니다. 실제 제품 사진을 넣는 것을 권장합니다.
- 그림자 경계가 약간 부드러워지고, 사진 전체 노출(흐린 날)에는 코르크 밝기를 맞추지 않습니다.
- 자동 지정: 포함 점 1개 + 제외 점만 주면 길 일부가 빠질 수 있습니다(길을 한 번 더 터치). 그림자 위를 터치하면 그림자만 잡힐 수 있습니다.
- 자동 변환 결과 품질은 Gemini에 달려 있습니다. Gemini가 구도를 바꾸거나 길이 아닌 곳을 크게 바꾸면 결과를 버리고 사유를 표시합니다. 길 위 사람·물체가 작으면 함께 코르크로 칠해질 수 있습니다(작은 구멍 메움).
- 원본 해상도가 Gemini 결과보다 크면 길 부분은 확대된 결과라 약간 부드러워 보일 수 있습니다.
- 요청 중 [취소]해도 이미 보낸 요청은 서버에서 처리되어 요금이 나갈 수 있습니다.
- 단계별 화면의 고품질 다듬기: 길 주변에 무늬가 거의 없으면(민무늬 벽·하늘) 정렬에 실패해 로컬 결과를 유지합니다.
- PDF의 글자는 윤곽선으로 그려져 선택·복사할 수 없습니다.
